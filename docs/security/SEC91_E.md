## 8. Remaining limitations
- `strict` fallback is per instance: N serverless instances allow up to N × limit while Redis is down. Only `closed` removes that.
- IP trust is platform-derived; only two routes adopt the helper (the rest are SEC-B's, §6.1).
- Redaction replaces every query value — log lines lose non-secret parameters (e.g. the searched domain) by design.
- `getTrustedClientIp` trusts `process.env.VERCEL`; a non-Vercel deployment must set `TRUSTED_PROXY_HOPS` or accept socket-peer keying.
- Meta/Pixabay/SerpAPI/BuiltWith/Stack Exchange still carry credentials in URLs (provider requirement or unverified header support); upstream access logs at the provider and any HTTP proxy in between can still see them.
