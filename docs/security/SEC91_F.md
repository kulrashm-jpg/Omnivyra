## 7. Remaining limitations
- R1-METHOD recognises `if`/`else if`, `switch`, and ternary dispatch on `req.method`/`method`; a method test stored in another variable (`const isGet = …`) or a handler map is not recognised (none exist today). R2/R3 remain per file.
- Prelude evidence is textual-order based: a primitive call in shared code before a branch covers it even if that call sits in a closure the branch never invokes.
- Migration views created inside DO blocks are not scanned for security_invoker; a dynamically named table only needs *some* `ENABLE ROW LEVEL SECURITY` in its block. Content edits to frozen historical migrations are not detected.
- SSRF: lib browser-only detection is heuristic; `${this.baseUrl}`-style hosts are flagged (annotate if safe); URLs built across multiple statements still rely on the existing variable rules.
- Secrets: pattern-based; unknown providers and split/encoded secrets are not detected; the Twitter-style bearer shape relies on the fingerprint allowlist. Git history is not scanned.
