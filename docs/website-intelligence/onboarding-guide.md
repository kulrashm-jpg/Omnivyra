# Website Intelligence Onboarding Guide

1. Create or select the customer website in Omnivera.
2. Open `/website-intelligence?company_id=<company_id>`.
3. Generate a WordPress setup token.
4. Install and activate the WordPress plugin.
5. Paste the setup token in Settings > Omnivera.
6. Confirm the plugin shows Connected.
7. Run Sync Now from the plugin.
8. Visit the public WordPress site and confirm tracking is detected.
9. Submit a test form and confirm attribution appears after aggregation.
10. Run Generate signals in Omnivera.

Success criteria:
- WordPress plugin heartbeat is fresh.
- Tracking status is active.
- At least one page view is visible.
- Form attribution is present for the test lead.
- No critical operational alerts are open.
