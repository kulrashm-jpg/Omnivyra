# Attribution Explanation Guide

Website Intelligence captures:
- First touch
- Last touch
- UTM source, medium, campaign, content, term
- Referrer
- Landing page
- Current page
- Anonymous/session IDs
- Consent state

Current model:
- Capture-time snapshots on lead conversion.
- First-touch and last-touch reports.
- Assisted conversion summaries from campaign touchpoints.

Limitations:
- Multi-touch weighting is not yet a weighted revenue model.
- Anonymous identity stitching depends on future person graph linkage.
