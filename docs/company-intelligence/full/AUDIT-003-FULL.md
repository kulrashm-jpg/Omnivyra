# AUDIT-003 — Company Intelligence & AI Generation Certification (FULL EDITION)

> **Archival Full Edition.** Maintained version: [`../architecture/AUDIT-003.md`](../architecture/AUDIT-003.md). Frozen at ratification. Corrections via [amendments](../amendments/README.md).

**Method:** three targeted read-only passes (crawl internals; prompts + grounding; competitors + confidence + safeguards). **Classification: Hybrid.**

**Two corrections to prior assumptions, established by deep reading:** (1) "language refine on read" is **not** an LLM call — `refineLanguageOutput` is rule-based only (regex filler removal, tone word-swaps, punctuation), env-flag-gated. (2) Intelligence enrichment (`runCompanyContextEnrichment`) makes **zero** LLM calls despite tagging its output `ai_inferred` — it is 100% deterministic regex/heuristic inference.

---

## 1. Intelligence Generation Architecture

The actual pipeline, each stage marked [DET] deterministic / [AI] LLM: Website → **CRAWL [DET]** (root + 3 keyword-scored same-domain pages, 8s/5MiB caps, 120s process cache, SSRF-pinned safeFetch) → **DETERMINISTIC EXTRACTION [DET]** (metadata, social links, top-10 sentence highlights ≤2000 chars) → **FINGERPRINT + CHANGE DECISION [DET]** (sha256 L0/L1/L2) → **REFRESH GATE [DET]** (16-branch policy; can STOP the pipeline or route METADATA_ONLY) → **EVIDENCE CLEANING [AI]** → **PROMPT CONSTRUCTION [DET]** (evidence JSON + archetype context + "return null with source=missing") → **LLM [AI]** (gpt-4o-mini, temp 0, JSON mode, via gateway) → **POST-PROCESSING [DET]** (zod normalization, Low⇒missing) → **CLASSIFICATION [DET]** (classifier **overrides** AI industry/category) → **PARALLEL DRAFTS [AI]** (strategy temp 0.1 + marketing temp 0.2) → **COMPETITOR ENGINE [DET]** → **VALIDATION [DET]** → **CONFIDENCE [DET]** (composite = max(existing, new) — monotonic) → **PERSISTENCE [DET]** → consumers. There is **no chunking/embedding/vector retrieval anywhere** — "retrieval" is the deterministic 4-page crawl plus structured field reads.

## 2. Crawl Pipeline Certification

Two crawlers exist: the profile-enrichment crawl (`crawlWebsiteSources`, ≤4 pages) and a separate BFS "Website Intelligence" crawler (`crawlerService.ts:450`, default 250 pages → `canonical_pages`), which feeds enrichment signals but not the refine path. **No scheduled crawl** — the daily scheduler reads with `autoRefine:false`; the cron ingests GA4 only. All profile crawling is lazy/on-demand (refine, staleness ≥7d, setup, enrichment). Scope: root + top-3 keyword-scored same-domain links; 8s root / 5s sub-page timeouts; 5 MiB/page; 2,000-char summaries; ≤40 sources; ≤8 socials; 3 redirects (each SSRF-revalidated and IP-pinned); asset/binary filter. **robots.txt is not honored** by the profile crawler (the BFS crawler fetches it but only records presence). Cache: per-process Map, key = trimmed URL string (global across tenants/workflows), 120s TTL, 256 FIFO, only successful fetches cached. Change detection: L0 (etag/last-modified/content-length), L1 (html/nav/favicon/logo/og hashes), L2 (business: company name, JSON-LD product/service types, CTA, contact, socials, brand colors) → UNCHANGED / COSMETIC (L1-only) / BUSINESS (1–2 L2) / MAJOR (name change or ≥3 L2). **JSON-LD is parsed for fingerprinting only, not profile metadata.** 16-branch refresh policy (admin override → pending → degraded → kill-switch → manual → cooldown [enterprise 1d / pro 3d / free 7d] → verdict-driven → budget), fail-open. Evidence before AI: page summaries, discovered metadata (10 fields), fingerprint bundle + change decision, ranked social links, the full existing profile, bootstrap columns, knowledge version + refresh history, BFS signals (if previously run), and Wikidata facts — the last **not wired into the refine evidence bundle**.

## 3. Grounding Certification

**No shared grounding pipeline — five distinct mechanisms:** (a) crawl evidence (cleaned summaries JSON; extraction only, and the strategy draft adds blogs/posts); (b) existing profile (ad-hoc serialization, a different shape per caller — marketing intel, PT, all six define-* chats, infer-PT); (c) the KG grounding block ("ALREADY KNOWN — never ask" + next-gap + readiness; **define-target-customer only**); (d) `buildCompanyUnderstanding` (profile + Wikidata firmographics + Wikipedia summary; Crunchbase/Bloomberg adapters dark; **suggest-competitors only**); (e) public signals (`canonical_pages` crawl metadata; context enrichment, no LLM). Notable: the extraction prompt receives `_currentProfile` but **never uses it** — extraction is grounded in crawl evidence alone. Confidence contributes to grounding only through the KG path (1 of 9 AI workflows). **Certified: AI endpoints do not use the same grounding**; the engine built to unify this (KG) has 1-of-6 adoption.

## 4. AI Workflow Inventory

All 13 LLM call sites flow through one seam (`runCompletionWithOperation` → billing guard → model routing/cost gate → retry + cross-provider fallback), gpt-4o-mini, per-call temperature and format: evidence cleaning (temp 0), profile extraction (temp 0, zod-normalized), missing-field questions (temp 0, allow/block filter), strategy draft (temp 0.1, crawl + blogs + posts, the reference cliché filter), marketing intelligence draft (temp 0.2, profile-only), problem-transformation refine (temp 0, strict-JSON retry), and the six define-* chats + infer-PT + generate-marketing-intelligence + suggest-competitors. Non-LLM workflows previously assumed to be AI: language refinement (rules), context enrichment (regex heuristics), competitor discovery/ranking (deterministic + SerpApi), classification (rules), KG (pure derivation), fingerprint/change/gate (pure).

## 5. Field Generation Matrix

`website_url` Excellent; identity/facts/socials/logo High; engine-path competitors High (chat path Low); strategy fields High (only workflow with a semantic quality filter); products_services/target_audience Medium; unique_value Medium (broken confidence key); industry/category Medium (classifier override + generic `'business_operations'` fallback); commercial 7 Medium (define-target-customer chat, temp 0.3, **zero server-side content validation on save, then locked**); brand_voice/goals Low (evidence the base can't support); marketing intelligence 7 Low (profile-only grounding, **no cliché filter**, no save validation); campaign_purpose Low (unguarded model-driven loop); problem/transformation 9 Low (invention-licensed prompts; deterministic fallback fabricates → **Very Low**).

## 6. Confidence Certification

Every calculation site was enumerated: `computeConfidenceScore` (12-field band-weighted → 0-100), refine per-field bands, PT uniform `'Medium'`, KG `bandToConfidence`, provenance `readAiConfidence` (defaults to `'medium'` when absent), intelligence readiness, context quality (`reliability = avgConf×55 + confirmed×35 − conflicting×12 − stale×8`), unified competitor intel per-row. Completeness is presence-only — a separate axis that ignores bands. **Seven certified inconsistencies:** (1) key mismatch `company_name`/`unique_value_proposition` (written) vs `name`/`unique_value` (read) — KG nodes permanently 'low'; (2) `business_classification` vs `pricing_model` mismatch for the business-model node; (3) `'Needs Review'` band outside every enum → collapses to 'low' or the fabricated 'medium'; (4) PT fields uniformly 'Medium' regardless of quality; (5) `overall_confidence` monotonic (`Math.max`) — can never decrease; (6) two duplicate score columns (`overall_confidence`, `confidence_score`); (7) completeness (presence) vs confidence (bands) unreconciled. Consumers: UI badge; customer-success stack with a hard 60 threshold in four services.

## 7. Hallucination Prevention Matrix

Safeguards inventoried with their gaps: temp 0 + JSON mode (extraction/PT; chats run 0.2–0.3); explicit no-invent prompt rules (extraction, MI, suggest-competitors — but **infer-PT and PT-fill explicitly permit inference**); zod normalization (extraction only; shape not factuality); Low⇒missing; classifier override of AI industry (also overrides users, falls to `'business_operations'`); competitor gates (blocklist + product-first tier + final gate minScore 42 + self-scrub + read revalidation — **no DNS/HTTP identity check anywhere**); user_locked_fields (extraction-owned fields never locked); fill-empty-only (per-endpoint); website validation (privileged-role bypass); strict-JSON retry + deterministic fallback (PT); grounding enforcement + cliché filters (draft-side only). **Certified critical gap:** the define-* chat → client → `POST /api/company-profile` path performs **no server-side content validation** — seven commercial, seven marketing, nine PT fields, and `campaign_purpose_intent` reach the DB exactly as the LLM produced them, laundered as a "user save" that also *locks* them. suggest-competitors output is prompt-only validated. Thin evidence ceiling (4 pages × 2,000 chars). Confidence-trust soft failure from key mismatches (correctly-extracted High fields read as low; absent provenance reads as medium).

## 8. Competitor Intelligence Certification

Discovery sources (all contributing): stored names, archetype-native seeds, **10 hardcoded named peer packs** (all creator/media — Morning Brew, The Hustle, Lenny's, Ali Abdaal, etc.; no product-SaaS pack), **SerpApi Google live discovery** (top-5 organic per keyword, ≤8 keywords, geography appended to query, budget-gated, key optional → silently disabled), geo-filtered known-dataset fallback (only when SERP yields 0), and user-guided steering. Ranking: inverse-SERP-position weighting → multi-dimension scoring (product/workflow/market fit; marketOverlap = geography×0.55 + segment×0.45) → **product-first tier gate** (business-first archetypes only: content/media → facilitated, agencies → secondary, else requires functional overlap ≥~0.70 AND segment alignment; locked by 8 contract tests) → **final gate** (minScore 42, enrichment-confidence floor, positioning completeness, dominance checks) → market substitutes only when no strong named competitor ≥70. Geography/industry/business-model aware. Validation: self/platform domain scrub at write AND read; 15-host platform blocklist + generic-agency token filter; read-time revalidation re-runs the gate (clears to `[]` on error). **No network-level identity verification of competitor domains exists anywhere.** The chat path (suggest-competitors) bypasses the entire engine.

## 9–11. Goals / Audience / Messaging Certifications

**Goals:** evidence = crawl summaries; prompt = shared extraction prompt (one field of 12); zod shape + band enum only — no goal-specific rules; never lock-listed. **Audience:** two generation paths — extraction (crawl-grounded, temp 0) for `target_audience`, and the define-target-customer chat (profile+KG-grounded, temp 0.3, client-staged, **no server-side content validation on save**) for the commercial pair; only the commercial pair is lockable. **Messaging:** three paths — extraction (`brand_voice`/`unique_value`), the marketing-intelligence draft (**profile-only grounding, no crawl evidence**, temp 0.2, contamination + audience-led checks), and the define-marketing-intelligence chat; refine merges drafts fill-missing-only; `unique_value` carries the certified confidence key mismatch.

## 12. Intelligence Consumer Matrix

Content, campaigns, Strategic/Intelligent Mix, recommendations, reports, trends, engagement, and creator consume the whole profile as AI grounding — inheriting every upstream generation defect verbatim. MarketPulse and recommendations additionally consume `company_context_intelligence` directly (the ungated second channel). Analytics/customer-success/onboarding consume the confidence numbers (the monotonic-max and band defects propagate into activation and conversion scoring). AI runtime uses `report_settings` as storage.

## 13. AI Duplication Register

Model/temp/JSON-mode call boilerplate in 13 sites; `JSON.parse`+default per workflow; strict-JSON retry implemented twice; the PT prompt/schema in three places (a fourth restatement in infer-PT); the marketing-intelligence 7-field list in ≥4 files; string/array coercion helpers in ≥6 files; the "server picks next question + safety-net fill" flow duplicated across two chats; audience-led grounding scaffolding wired identically in three draft services; five grounding serializations of the same profile; two competitor-generation systems (engine vs chat) with disjoint validation.

## 14. Final Intelligence Certification — where incorrect intelligence originates

Certified origination points, in causal order: (1) the 4-page × 2,000-char evidence ceiling; (2) inference-permissive prompts (infer-PT, PT-fill) whose output enters the same fields as evidence-derived data with no distinguishing marker; (3) the unvalidated chat-save path laundering temp-0.2–0.3 LLM output into a "user save" that both persists unvalidated and locks it as user truth; (4) the competitor chat bypass (prompt-only validation, no domain existence check); (5) confidence contract drift making trust signals wrong in both directions, plus monotonic-max; (6) classifier fallback to `'business_operations'` and classifier-overwrites-user; (7) staleness windows (7-day gate + cooldowns + no scheduled crawl).

## 15. Final Classification

**Hybrid** — a deterministic skeleton with AI confined to bounded generation points, and a validation regime strong at the center and absent at the edges. Not "AI-Driven": the load-bearing decisions are deterministic — page selection, fingerprinting, change detection, the 16-branch refresh gate (which frequently prevents AI from running at all, with token-savings accounting), industry classification (which *overrides* the AI), the competitor ranking/gating engine, context enrichment (zero LLM), and language refinement (pure rules); three subsystems widely assumed to be AI are certified deterministic here. Not "Deterministic/Mostly Deterministic": every substantive intelligence *value* — products, audience, voice, goals, unique value, strategy, marketing intelligence, problem/transformation, and conversational field capture — originates from 13 LLM call sites. Not "Highly Fragmented" as a primary classification, though fragmentation is the chief defect within: five grounding mechanisms, ten duplicated scaffolds, a broken confidence contract, and one endpoint of six on the unification engine. The pipeline core (crawl → gate → extract → normalize → classify → persist) is a single coherent, well-instrumented flow; the fragmentation lives in the conversational periphery and the trust/confidence layer. The deterministic control plane is production-grade and cost-disciplined; the AI generation plane is centrally well-guarded (temp-0 + zod + no-invent prompts + classifier override on the refine path) but **peripherally unguarded** (client-mediated chat persistence with no server-side validation, prompt-only competitor validation, inference-permissive endpoints) and undermined by a broken confidence contract.
