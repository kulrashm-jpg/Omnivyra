# Identity Runtime Risk Register — Phase 1

**Repo:** `c:\virality` — `identity-spine-enforcement` branch
**Source-grounded.** Runtime risks only — every entry derived from observable code at the cited file:line.

Severity ladder:
- **CRITICAL** — privilege escalation, data integrity loss, complete-flow breakage on current schema, or attribution gap that violates audit/compliance
- **HIGH** — partial-state corruption, drift between authoritative sources, silent guard bypass
- **MEDIUM** — degraded behavior, misleading errors, latent bugs that fire only in specific paths
- **LOW** — cosmetic, comment drift, unused-but-harmless artifacts
